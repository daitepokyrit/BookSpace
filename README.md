# BookSpace

Готовый статический многостраничный фронтенд онлайн-библиотеки. Проект не использует backend, базу данных, сборщик или установку зависимостей.

## Локальный запуск

1. Скачайте архив и распакуйте папку `BookSpace`.
2. Дважды щёлкните `index.html` — сайт откроется в браузере через `file://`.
3. Для стилей Bootstrap и Bootstrap JavaScript требуется интернет-соединение: библиотеки подключены через CDN. Без интернета останутся доступны собственные HTML/CSS/JS, но часть оформления и интерактивных компонентов Bootstrap может быть недоступна.

## Страницы

- `index.html` — главная, подборки и популярные книги.
- `catalog.html` — поиск, жанровая фильтрация и сортировка на JavaScript.
- `product.html` — подробности книги и отзывы в accordion.
- `order.html` — демонстрационная форма с клиентской проверкой и подтверждающим modal; ничего не отправляется на сервер.
- `about.html` — подробное описание онлайн-библиотеки и её идеи.
- `contacts.html` — контактная информация и ответы на частые вопросы.

## Добавленные функции для контрольной работы

1. **Избранное:** кнопка-сердце у карточки сохраняет выбор в браузере через `localStorage`.
2. **Фильтр избранного:** в каталоге можно оставить на экране только отмеченные книги.
3. **Светлая и тёмная тема:** переключатель запоминает выбор в браузере.
4. **Подбор книги:** главная страница случайным образом открывает одну из книг каталога.
5. **Сортировка по автору:** в каталоге добавлен соответствующий пункт сортировки.

Все функции реализованы на JavaScript без backend; для пользовательских настроек применяется `localStorage`.

## Публикация в GitHub

Создайте новый репозиторий на GitHub, затем загрузите в него содержимое папки `BookSpace` (включая подпапки `css`, `js` и `images`). Для публикации как GitHub Pages выберите в настройках репозитория раздел **Pages**, источник **Deploy from a branch**, ветку `main` и папку `/ (root)`. После публикации главной страницей будет `index.html`.

## Технические заметки

- В каталоге 12 реальных книг. Все обложки сохранены локально в `images/` как изображения лицевой стороны, поэтому самим изображениям интернет для загрузки не требуется.
- Обложки сверены по ISBN в Open Library: 9780547928227 (The Hobbit), 9780451524935 (1984), 9780743273565 (The Great Gatsby), 9780590353427 (Harry Potter and the Sorcerer’s Stone), 9780156012195 (The Little Prince), 9780141439518 (Pride and Prejudice), 9780061120084 (To Kill a Mockingbird), 9780316769488 (The Catcher in the Rye), 9780441172719 (Dune), 9780061122415 (The Alchemist), 9780451528018 (The Hound of the Baskervilles), 9780141439846 (Dracula). Источник: [Open Library Covers API](https://openlibrary.org/dev/docs/api/covers). Логотип BookSpace остаётся локальным SVG в `images/`.
- На всех страницах общая навигация, семантические секции, видимые состояния фокуса и подписи к полям.
- Запрос в каталоге ищет в названии, авторе и жанре. Ссылка с жанром из главной страницы предзаполняет фильтр. Меню и расширенный футер едины на всех страницах.
- Каталог, карточки, страницы книг и выпадающий список формы заказа используют один массив `books` из `js/script.js`.
- Заявка работает только в браузере и предназначена для демонстрации.
- Ранее приложенные методички практик №9, №10 и №11 в доступном архиве указанного чата и рабочем пространстве не обнаружены. Поэтому проект выполнен по критериям, перечисленным в задаче; сверка с оригинальными методичками не проводилась.

## Проверки

- Проверен синтаксис `js/script.js` командой Node.js.
- Проверены локальные ссылки на страницы, скрипты, стили, логотип и все 12 обложек; отсутствующих локальных файлов не найдено.
- Проверены порядок четырёх пунктов меню на всех шести страницах и наличие контактного и краткого информационного блока в футере.
- Проверены данные каталога и формы: список заказа формируется из массива книг, а ссылки выбора передают название книги.
- Проверены HTTP-ответы и JPEG-формат загруженных обложек; шесть новых изображений визуально просмотрены как отдельные фронтальные обложки.
- Браузерный прогон всех страниц не выполнен: среда запретила открытие локального `file://` адреса. Для локального запуска откройте `index.html`; Bootstrap по-прежнему загружается с CDN.
